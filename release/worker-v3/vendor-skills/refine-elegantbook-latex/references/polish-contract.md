# Historical Polish Contract — Deprecated

Status: `deprecated_non_normative`

The former write-oriented polish contract is no longer part of the active skill. The approved production model does not permit a downstream LaTeX-only stage to delete content, change metadata, reclassify headings, choose boxes, prune images, add answer space, or patch the template after `render_plan` is frozen.

The public CLI accepts only `--mode audit`. Findings must be routed as follows:

- source identity, transcription, loss, duplication, or representation: Spec 03;
- hierarchy, teaching semantics, box choice, media binding, or render parameters: Spec 04;
- legal serialization, assets, template integrity, compilation, or mechanical layout execution: Spec 05;
- page-level discovery and acceptance: Spec 06, followed by return to the owning stage.

Historical mutation helpers remain in the script only for regression archaeology and are not callable through the supported CLI. They must not be copied into a new skill, invoked by importing the module, or used to produce a promoted ZIP.
